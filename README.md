# Smalltech — сайт сообщества

Сайт сообщества **Смоллтех** — объединения инженеров, деврелов и менеджеров технобренда малых
и средних ИТ-компаний. Мы делаем смоллтех привлекательным через коллаборацию, а не конкуренцию.

На сайте: манифест сообщества, исследование болей smalltech и midtech команд (468 анкет, 6 конференций),
история и партнёры сообщества, записи докладов и презентации с митапов, форматы партнёрства и способы
присоединиться.

**Сайт:** https://smalltech.ontico.ru
**Сообщество в Telegram:** https://t.me/small_tech

Сайт открыт к контрибьютам: поправить формулировку или опечатку может любой участник — прямо в браузере.

## Как предложить правку текста

Все тексты сайта лежат в папке [`src/content`](src/content), по одному файлу на страницу, отдельно
от вёрстки. Чтобы предложить новую формулировку, не нужно ничего устанавливать — достаточно аккаунта
на GitHub. Пошаговая инструкция (какой файл за какую страницу отвечает, что в файлах можно менять,
а что нельзя, кто и как принимает правку): [`src/content/README.md`](src/content/README.md).

## Как запустить сайт у себя

Нужны [Node.js](https://nodejs.org) 20 и npm.

```bash
git clone https://github.com/picksi7/Smalltech-base.git
cd Smalltech-base
npm ci
npm run dev
```

Сайт откроется на http://localhost:8080 и будет обновляться при каждой правке файлов.

Другие команды:

```bash
npm run build   # сборка сайта в папку dist (страницы готовятся заранее, в виде HTML)
npm test        # тесты
npm run lint    # проверка кода
```

## Как сайт попадает в интернет

Ветка `main` публикуется на сайт автоматически: любое изменение, попавшее в `main`, GitHub Actions
собирает и выкладывает на GitHub Pages (см. [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)).
Отдельной тестовой версии нет, поэтому изменения вносятся через pull request и проверяются владельцем
репозитория до слияния.

## Из чего сделан сайт

Vite, React, TypeScript, Tailwind CSS, shadcn/ui.

- `src/content` — тексты страниц (то, что чаще всего правят);
- `src/pages` — страницы сайта: вёрстка, которая берёт тексты из `src/content`;
- `src/components/site` — шапка, подвал и общие блоки;
- `src/assets` — изображения;
- `public` — файлы, которые попадают на сайт как есть.
